查看任何 X（Twitter）账号从哪个国家发帖 — 国旗、VPN 标记和来源平台 — 无需打开任何一个个人资料。直接从 X 自身的数据中读取，不使用第三方地理定位。

将鼠标悬停在个人资料上，国旗就会显示。在信息流中启用国旗显示，每个用户名旁边都会出现一面国旗。在手机上向右滑动即可按需查看位置。

简而言之：一个在你阅读的地方直接运行的X账号位置检查器——无需访问网站，无需粘贴用户名，屏幕上的每个资料都会自动检查。


您将获得的功能

- 悬停卡片、个人资料页面和时间线内的国外国旗
- 来源平台和应用商店国家 — 确认或驳斥所述位置
- 当 X 自身无法验证位置时显示红色 VPN 标记
- 将任意帖子复制为嵌入国旗的PNG图片——右键一下，随处可贴
- 按国家或地区过滤帖子 — 折叠到"显示"按钮后面或完全隐藏
- 按关键词高亮帖子，或按简介中堆叠国旗的账号高亮
- 标记低于阈值的账号（90 天、180 天、1 年、3 年）
- 按 X 组织归属过滤账号（政府、非政府组织、公司徽章）
- 每条规则的例外列表 — 在不禁用规则的情况下豁免特定账号
- 账号信息卡 — 认证状态、账号年龄、用户名更改次数、归属徽章、受保护账号指示器
- 在 Android 和触屏设备上向右滑动以显示
- 无需登录，无需 API 密钥，不会在长帖中间出现速率限制错误


X 速率限制，解决而非碰壁

您见过这种情况 — 国旗在帖串顶部出现，然后停止。或者您悬停的每个个人资料都在旋转，永远不会完成。这就是速率限制：X 每 15 分钟限制您 50 次查询，而一条热门的帖串中的账号数量远超此数。

这里的大多数个人资料不会消耗查询，因为它们已经缓存在您的浏览器中，或者由共享社区缓存回答。其余的在所有打开的 X 标签页之间由跨标签页代理分配，窗口的最后 30% 保留给您实际悬停的账号。

用完后，您会看到重置倒计时，而不是空白国旗。


国家信息的来源

您的浏览器使用您已登录的会话询问 x.com。中间没有我们的服务器，没有 IP 地理定位，没有第三方数据库。

它直接从 X 自身的账号元数据中读取国家信息 — 与 X 用于标记个人资料的字段相同 — 同时也读取账号下载 X 的应用商店国家。当商店国家与所述位置不同时，两者都会显示。当 X 将位置标记为未验证时，会显示 VPN 标记。当商店国家即使带有未验证标签也能证实所述位置时，标记会被抑制。

因此，它的准确性与 X 自身的数据完全一致。在较旧或已锁定的账号上偶尔会缺失。除了您已打开的 X 会话外，无需登录和 API 密钥。


过滤

选择国家或整个地区（13 个世界地区，200 多个单独国家），然后保持不变，折叠到"显示"按钮后面，或隐藏。折叠是默认设置，因为静默删除内容的时间线不值得信任。

您还可以按账号年龄、X 组织归属以及简介中堆叠多个国旗的账号进行过滤。每条规则都有自己的例外列表，还有一个全局的"始终显示"白名单，可以一次性覆盖所有规则。

关键词高亮使用 CSS Highlights API — 它从不触碰 DOM，因此 X 的 React 永远不会察觉。支持表情符号关键词，简介中匹配的国旗表情符号会显示可见的轮廓环。


把帖子复制成图片

右键点击任意帖子——或使用悬停卡片上的按钮——它就会以嵌入国旗的PNG形式进入剪贴板。粘贴到回复或聊天中：位置信息随截图一起传达。


隐私

绝不会读取：您的 Cookie 和会话令牌、您滚动经过的简介和帖子、您的浏览历史。不是设置问题。它绝不会读取它们。

扩展中没有分析或遥测。结果在您的浏览器中存储 30 天，一个按钮即可全部清除。

源代码公开（MIT 许可证），因此您可以验证这一切，而不必相信我们的话。


共享缓存，默认开启

您的查询回答他人的查询，他人的查询回答您的查询，这就是让速率限制远离您的原因。

发送的内容：查询的用户名、其国家和 VPN 标志，以及一个随机的安装 ID。不涉及您的任何信息，不涉及您阅读的内容。设置中的一个开关可将其关闭 — 关闭它也会停止后台预取。

缓存服务器是开源的。您可以运行自己的。

每一次安装都让国旗对其他所有人即时显示——这是用的人越多越好的唯一部分。
