ดูว่าบัญชี X (Twitter) ใด ๆ โพสต์จากประเทศอะไร — ธงประเทศ ป้าย VPN และแพลตฟอร์มต้นทาง — โดยไม่ต้องเปิดโปรไฟล์แม้แต่โปรไฟล์เดียว อ่านโดยตรงจากข้อมูลของ X เอง ไม่มีการระบุตำแหน่งทางภูมิศาสตร์จากบุคคลที่สาม

เลื่อนเมาส์ไปที่โปรไฟล์แล้วธงก็ปรากฏขึ้น เปิดธงในฟีดแล้วธงจะปรากฏข้างชื่อผู้ใช้ทุกคน ปัดไปทางขวาบนมือถือเพื่อแสดงตำแหน่งตามต้องการ

สรุปสั้นๆ: ตัวตรวจสอบตำแหน่งบัญชี X ที่ทำงานตรงที่คุณอ่าน — ไม่ต้องเปิดเว็บไซต์ ไม่ต้องวางชื่อผู้ใช้ ทุกโปรไฟล์บนหน้าจอถูกตรวจสอบอัตโนมัติ


สิ่งที่คุณจะได้รับ

- ธงประเทศในการ์ดโฮเวอร์ บนหน้าโปรไฟล์ และในไทม์ไลน์
- แพลตฟอร์มต้นทางและประเทศของแอปสโตร์ — ยืนยันหรือขัดแย้งกับตำแหน่งที่ระบุ
- ป้าย VPN สีแดงเมื่อ X เองไม่สามารถตรวจสอบตำแหน่งได้
- คัดลอกโพสต์ใดก็ได้เป็นภาพ PNG พร้อมธงฝังอยู่ — คลิกขวาครั้งเดียว พร้อมวางได้ทุกที่
- กรองโพสต์ตามประเทศหรือภูมิภาค — ย่อไว้หลังปุ่ม "แสดง" หรือซ่อนทั้งหมด
- เน้นโพสต์ตามคำสำคัญ หรือตามบัญชีที่สะสมธงในประวัติ
- ทำเครื่องหมายบัญชีที่อายุน้อยกว่าเกณฑ์ (90 วัน, 180 วัน, 1 ปี, 3 ปี)
- กรองบัญชีตามสังกัดองค์กร X (ป้ายหน่วยงานรัฐ, องค์กรไม่แสวงหากำไร, บริษัท)
- รายการยกเว้นต่อกฎ — ยกเว้นบัญชีเฉพาะจากตัวกรองใด ๆ โดยไม่ต้องปิดการใช้งานกฎ
- การ์ดข้อมูลบัญชี — สถานะการยืนยัน, อายุบัญชี, จำนวนการเปลี่ยนชื่อผู้ใช้, ป้ายสังกัด, ตัวบ่งชี้บัญชีที่ป้องกัน
- ปัดไปทางขวาเพื่อแสดง บน Android และอุปกรณ์หน้าจอสัมผัส
- ไม่ต้องเข้าสู่ระบบ ไม่ต้องใช้คีย์ API ไม่มีข้อผิดพลาดการจำกัดอัตรากลางเธรดยาว


การจำกัดอัตราของ X แก้ไขแทนที่จะชน

คุณเคยเห็นแล้ว — ธงปรากฏที่ด้านบนของเธรด แล้วหยุด หรือทุกโปรไฟล์ที่คุณเลื่อนเมาส์ไปหมุนแล้วไม่เสร็จ นั่นคือการจำกัดอัตรา: X ตัดคุณที่ 50 การค้นหาต่อ 15 นาที และหนึ่งเธรดที่พลุกพล่านมีบัญชีมากกว่านั้น

โปรไฟล์ส่วนใหญ่ที่นี่ไม่เคยใช้การค้นหาเพราะถูกแคชไว้ในเบราว์เซอร์ของคุณแล้วหรือตอบจากแคชชุมชนที่ใช้ร่วมกัน ส่วนที่เหลือถูกปันส่วนในแท็บ X ที่เปิดอยู่ทั้งหมดโดยโบรกเกอร์ข้ามแท็บ และ 30 เปอร์เซ็นต์สุดท้ายของหน้าต่างถูกสงวนไว้สำหรับบัญชีที่คุณเลื่อนเมาส์ไปจริง ๆ

เมื่อหมด คุณจะได้รับการนับถอยหลังสู่การรีเซ็ต ไม่ใช่ธงว่างเปล่า


ประเทศมาจากไหน

เบราว์เซอร์ของคุณถาม x.com โดยใช้เซสชันที่คุณล็อกอินอยู่แล้ว ไม่มีเซิร์ฟเวอร์ของเราคั่นกลาง ไม่มีการระบุตำแหน่งทางภูมิศาสตร์ด้วย IP ไม่มีฐานข้อมูลบุคคลที่สาม

มันอ่านประเทศโดยตรงจากข้อมูลเมตาของบัญชี X — ฟิลด์เดียวกับที่ X ใช้ในการติดป้ายโปรไฟล์ — และยังอ่านประเทศของแอปสโตร์ที่บัญชีนั้นดาวน์โหลด X มา เมื่อประเทศของสโตร์แตกต่างจากตำแหน่งที่ระบุ ทั้งสองจะแสดงขึ้น เมื่อ X ทำเครื่องหมายตำแหน่งว่าไม่ได้รับการยืนยัน ป้าย VPN จะปรากฏขึ้น เมื่อประเทศของสโตร์ยืนยันตำแหน่งที่ระบุแม้จะมีป้ายไม่ได้รับการยืนยัน ป้ายนั้นจะถูกระงับ

ดังนั้นมันจึงแม่นยำเท่ากับข้อมูลของ X เอง บางครั้งขาดหายไปในบัญชีเก่าหรือบัญชีที่ถูกล็อก ไม่ต้องเข้าสู่ระบบและไม่ต้องใช้คีย์ API นอกเหนือจากเซสชัน X ที่คุณเปิดอยู่แล้ว


การกรอง

เลือกประเทศหรือภูมิภาคทั้งหมด (13 ภูมิภาคโลก, 200+ ประเทศแต่ละประเทศ) จากนั้นปล่อยไว้ ย่อไว้หลังปุ่ม "แสดง" หรือซ่อน การย่อเป็นค่าเริ่มต้น เพราะไทม์ไลน์ที่ลบสิ่งต่าง ๆ อย่างเงียบ ๆ ไม่ใช่ไทม์ไลน์ที่คุณไว้วางใจได้

คุณยังสามารถกรองตามอายุบัญชี ตามสังกัดองค์กร X และตามบัญชีที่สะสมธงหลายอันในประวัติ ทุกกฎมีรายการยกเว้นของตัวเอง และมีรายการอนุญาต "แสดงเสมอ" ทั่วโลกที่แทนที่กฎทั้งหมดพร้อมกัน

การเน้นคำสำคัญใช้ CSS Highlights API — มันไม่เคยแตะ DOM ดังนั้น React ของ X ไม่เคยสังเกตเห็น รองรับคำสำคัญอีโมจิ และธงอีโมจิที่ตรงกันในประวัติจะมีวงแหวนโครงร่างที่มองเห็นได้


คัดลอกโพสต์เป็นรูปภาพ

คลิกขวาที่โพสต์ใดก็ได้ — หรือใช้ปุ่มในการ์ดโฮเวอร์ — แล้วมันจะเข้าคลิปบอร์ดเป็น PNG พร้อมธงฝังอยู่ วางในการตอบกลับหรือแชท: บริบทตำแหน่งเดินทางไปพร้อมกับภาพหน้าจอ


ความเป็นส่วนตัว

ไม่เคยอ่าน: คุกกี้และโทเค็นเซสชันของคุณ ประวัติและโพสต์ที่คุณเลื่อนผ่าน ประวัติการท่องเว็บของคุณ ไม่ใช่เป็นการตั้งค่า มันไม่เคยอ่านมัน

ไม่มีการวิเคราะห์หรือเทเลเมทรีในส่วนขยาย ผลลัพธ์ถูกเก็บในเบราว์เซอร์ของคุณเป็นเวลา 30 วันและปุ่มเดียวล้างทั้งหมด

ซอร์สเป็นสาธารณะ (ใบอนุญาต MIT) ดังนั้นคุณสามารถตรวจสอบสิ่งเหล่านี้แทนที่จะเชื่อคำพูดของเรา


แคชที่ใช้ร่วมกัน เปิดตามค่าเริ่มต้น

การค้นหาของคุณตอบการค้นหาของผู้อื่นและการค้นหาของพวกเขาตอบคุณ นั่นคือสิ่งที่ทำให้การจำกัดอัตราห่างจากคุณ

สิ่งที่ถูกส่ง: ชื่อผู้ใช้ที่ถูกค้นหา ประเทศและธง VPN ของมัน และ ID การติดตั้งแบบสุ่ม ไม่มีอะไรเกี่ยวกับคุณ ไม่มีอะไรเกี่ยวกับสิ่งที่คุณอ่าน ปุ่มเดียวในการตั้งค่าปิดมัน — และการปิดมันยังหยุดการดึงข้อมูลล่วงหน้าในพื้นหลังด้วย

เซิร์ฟเวอร์แคชเป็นโอเพนซอร์ส คุณสามารถรันของคุณเองได้

การติดตั้งทุกครั้งทำให้ธงแสดงทันทีสำหรับทุกคน — ส่วนเดียวที่ยิ่งมีคนใช้ยิ่งดีขึ้น


สิทธิ์

x.com และ twitter.com เพราะนั่นคือที่ที่มันทำงาน พื้นที่เก็บข้อมูล สำหรับการตั้งค่าและแคชท้องถิ่น 30 วัน เมนูบริบท สำหรับสองรายการ: "คัดลอกโพสต์พร้อมธงตำแหน่ง" และทางลัดไปยังการตั้งค่า

นั่นคือรายการทั้งหมด มันไม่สามารถเห็นแท็บอื่นที่คุณเปิดอยู่ และไม่มีโค้ดระยะไกลถูกโหลด


สิ่งที่มันไม่ใช่

ไม่ใช่ตัวตรวจจับบอทหรือตัวจำแนกการปั่นการมีส่วนร่วม มันแสดงสัญญาณที่คุณไม่สามารถเห็นได้โดยไม่ต้องเปิดทุกโปรไฟล์ทีละอัน — ประเทศ แพลตฟอร์มต้นทาง สถานะ VPN อายุบัญชี สังกัด การยืนยัน การเปลี่ยนชื่อผู้ใช้ สิ่งที่คุณสรุปจากมันเป็นของคุณ
