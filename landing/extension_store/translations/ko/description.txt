X(트위터) 계정이 어느 국가에서 게시하는지 확인하세요 — 국가 국기, VPN 배지, 소스 플랫폼 — 프로필을 하나도 열지 않고도. X 자체 데이터에서 직접 읽어오며, 타사 지리 위치 확인은 사용하지 않습니다.

프로필에 마우스를 올리면 국기가 나타납니다. 피드에서 국기를 켜면 모든 사용자 이름 옆에 표시됩니다. 모바일에서는 오른쪽으로 스와이프하여 필요할 때 위치를 확인하세요.


제공 기능

- 호버 카드, 프로필 페이지, 타임라인에 인라인으로 국가 국기 표시
- 소스 플랫폼 및 앱 스토어 국가 — 명시된 위치를 확인하거나 반증
- X 자체에서 위치를 확인할 수 없을 때 빨간색 VPN 배지
- 국가 또는 지역별로 게시물 필터링 — "표시" 버튼 뒤로 접거나 완전히 숨기기
- 키워드로 게시물 강조 표시, 또는 약력에 국기를 쌓아둔 계정으로 강조 표시
- 기준치보다 최근 계정 표시 (90일, 180일, 1년, 3년)
- X 조직 소속으로 계정 필터링 (정부, NGO, 기업 배지)
- 규칙별 예외 목록 — 규칙을 비활성화하지 않고 특정 계정을 필터에서 제외
- 계정 정보 카드 — 인증 상태, 계정 생성일, 핸들 변경 횟수, 소속 배지, 보호 계정 표시기
- 위치 국기가 포함된 PNG 이미지로 게시물 공유 — 오른쪽 클릭 메뉴 또는 호버 카드 버튼
- Android 및 터치스크린 기기에서 오른쪽으로 스와이프하여 표시
- 로그인 불필요, API 키 불필요, 긴 스레드 중간에 속도 제한 오류 없음


X 속도 제한, 부딪히는 대신 해결

보셨을 겁니다 — 스레드 상단에 국기가 채워지다가 멈춥니다. 또는 마우스를 올린 모든 프로필이 빙글빙글 돌기만 하고 완료되지 않습니다. 그것이 속도 제한입니다: X는 15분당 50회 조회로 제한하며, 하나의 붐비는 스레드에는 그보다 더 많은 계정이 있습니다.

여기서 대부분의 프로필은 브라우저에 이미 캐시되어 있거나 공유 커뮤니티 캐시에서 응답되기 때문에 조회를 소모하지 않습니다. 나머지는 크로스탭 브로커가 열려 있는 모든 X 탭에 할당하며, 창의 마지막 30%는 실제로 마우스를 올리는 계정을 위해 예약됩니다.

소진되면 빈 국기가 아닌 재설정까지의 카운트다운이 표시됩니다.


국가 정보의 출처

브라우저가 x.com에 요청하며, 이미 로그인된 세션을 사용합니다. 중간에 당사 서버 없음, IP 지리 위치 확인 없음, 타사 데이터베이스 없음.

X 자체 계정 메타데이터에서 직접 국가를 읽어옵니다 — X가 프로필에 라벨을 지정하는 데 사용하는 동일한 필드 — 또한 계정이 X를 다운로드한 앱 스토어 국가도 읽습니다. 스토어 국가가 명시된 위치와 다를 경우 둘 다 표시됩니다. X가 위치를 미확인으로 표시하면 VPN 배지가 나타납니다. 미확인 태그가 있더라도 스토어 국가가 명시된 위치를 뒷받침하면 배지가 표시되지 않습니다.

따라서 X 자체 데이터와 정확히 동일한 정확도를 가집니다. 오래되었거나 잠긴 계정에서는 누락될 수 있습니다. 이미 열려 있는 X 세션 외에 로그인이나 API 키가 필요하지 않습니다.


필터링

국가 또는 전체 지역(13개 세계 지역, 200개 이상의 개별 국가)을 선택한 다음 그대로 두거나, "표시" 버튼 뒤로 접거나, 숨깁니다. 접기가 기본값입니다. 조용히 항목을 삭제하는 타임라인은 신뢰할 수 없기 때문입니다.

계정 연령, X 조직 소속, 약력에 여러 국기를 쌓아둔 계정으로도 필터링할 수 있습니다. 각 규칙에는 자체 예외 목록이 있으며, 모든 규칙을 한 번에 재정의하는 전역 "항상 표시" 허용 목록도 있습니다.

키워드 강조 표시는 CSS Highlights API를 사용합니다 — DOM을 전혀 건드리지 않으므로 X의 React가 이를 감지하지 못합니다. 이모지 키워드가 지원되며, 약력에서 일치하는 국기 이모지에는 눈에 보이는 윤곽선 링이 표시됩니다.


개인정보 보호

절대 읽지 않음: 쿠키 및 세션 토큰, 스크롤하여 지나가는 약력 및 게시물, 검색 기록. 설정이 아닙니다. 절대 읽지 않습니다.

확장 프로그램에 분석 또는 원격 측정이 없습니다. 결과는 브라우저에 30일간 저장되며 버튼 하나로 모두 삭제됩니다.

소스는 공개되어 있습니다(MIT 라이선스). 말만 믿지 않고 이 모든 것을 확인할 수 있습니다.


공유 캐시, 기본적으로 켜짐

귀하의 조회가 다른 사람의 조회에 응답하고 그들의 조회가 귀하의 조회에 응답합니다. 이것이 속도 제한을 피하는 방식입니다.

전송되는 것: 조회된 핸들, 해당 국가 및 VPN 플래그, 무작위 설치 ID. 귀하에 대한 정보 없음, 귀하가 읽는 내용에 대한 정보 없음. 설정의 토글 하나로 끌 수 있으며 — 끄면 백그라운드 사전 페칭도 중지됩니다.

캐시 서버는 오픈 소스입니다. 직접 실행할 수 있습니다.


권한

x.com 및 twitter.com, 확장 프로그램이 실행되는 곳이기 때문입니다. 저장소, 설정 및 30일 로컬 캐시용. 컨텍스트 메뉴, 두 개의 항목용: "위치 국기와 함께 게시물 복사" 및 설정 바로 가기.

이것이 전체 목록입니다. 열려 있는 다른 탭을 볼 수 없으며, 원격 코드가 로드되는 일도 없습니다.


무엇이 아닌가

봇 탐지기나 참여 농장 분류기가 아닙니다. 프로필을 하나씩 열지 않고는 볼 수 없는 신호를 표시합니다 — 국가, 소스 플랫폼, VPN 상태, 계정 연령, 소속, 인증, 핸들 변경. 이로부터 무엇을 결론 내릴지는 귀하의 몫입니다.


데스크톱에서는 Chrome, Edge, Brave. Android에서는 Lemur Browser. Firefox 및 Safari는 각 스토어를 통해.
